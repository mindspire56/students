# 生活工作台 (students)

集成式个人生活工作台 —— **单文件 HTML、零外部依赖、localStorage 本地持久化**，手机和电脑都能用，可「添加到主屏幕」当 App。

> 仓库由工作台搭建流程自动生成并上传。源码为单文件 `生活工作台.html`，双击即可在浏览器打开使用，无需联网、无需服务器。

### 模块清单（共 8 个）
1. **今日生活指数** —— 财务/习惯/身体/日程四维加权评分；逾期红标「今天要处理」，昨天未完成的自动顺延并可一键处理
2. **记账理财** —— 收支记录、预算进度、近 6 月对比柱状图、消费结构环形图、类型+分类+搜索三重筛选、Excel/CSV 导出
3. **习惯健康** —— 自由增删；勾选 / 计数 / 数值三种打卡方式；30 天热力图（可点格补卡）
4. **减脂健身** —— 体重体脂曲线 + 7 日均线、BMI、目标进度、热量缺口、可自定义周计划
5. **日程统筹** —— 增 / 改 / 删 / 完成；逾期与今日项自动进「今天要处理」
6. **待买清单** —— 增删改；买入可一键记进账本
7. **书影音收藏** —— 状态 / 星级 / 短评 / 封面墙 / 列表 / 年度统计
8. **暑假学习模式** —— 语数物化生五科今日打卡、按科任务清单、30 天学习热力图、暑假倒计时（v1.1 新增）

## 使用方式
1. 直接双击 `生活工作台.html` 在浏览器打开即可使用
2. 所有数据保存在**本机浏览器 localStorage**，关闭页面不丢
3. 建议每月点「导出 JSON 备份」一次；换设备 / 清缓存前务必先导出
4. 手机：用浏览器打开后「分享 → 添加到主屏幕」，即获得独立 App 图标（PWA 全屏）

## 数据安全机制
- 输入即存 localStorage；保存前自动写入安全快照
- 解析失败自动切快照；损坏内容留档到 `wb_life_v1_broken`
- 存储满 / 写入失败弹红色横幅说明原因，不静默丢数据
- 删除、清空均有二次确认

## 隐私说明
- 数据仅存于你自己的浏览器，**不经过任何服务器**
- 若部署为公开网址（如 GitHub Pages），链接公网可访问，请勿在页面预填真实金额 / 体重等隐私
